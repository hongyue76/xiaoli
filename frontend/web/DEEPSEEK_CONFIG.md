# DeepSeek AI API配置指南

## 🎯 快速配置（3步即可使用真实AI）

### 步骤1：申请API密钥

1. **访问DeepSeek平台**
   ```
   https://platform.deepseek.com/
   ```

2. **注册账号**
   - 点击"Sign Up"
   - 使用邮箱或手机号注册
   - 完成邮箱验证

3. **获取API密钥**
   - 登录后进入"API Keys"页面
   - 点击"Create New Key"
   - 复制生成的密钥（格式：`sk-xxxxx`）

### 步骤2：修改代码

打开文件：`frontend/web/src/components/AIChat.tsx`

找到第82行：
```typescript
'Authorization': 'Bearer sk-test-free-key',
```

替换为您的真实密钥：
```typescript
'Authorization': 'Bearer sk-你实际的密钥',
```

### 步骤3：重启前端

刷新浏览器页面或：
```bash
# 在前端目录重启
npm run dev
```

---

## ✅ 配置完成

现在切换到"DeepSeek AI"模式，就可以使用真实AI了！

## 📋 DeepSeek API说明

### API特性
- ✅ **免费使用**：有一定免费额度
- ✅ **中文友好**：对中文支持很好
- ✅ **法律能力强**：适合法律类问题
- ✅ **响应快速**：生成速度较快

### 计费说明
- **免费额度**：新用户有免费额度
- **按量付费**：超出后按tokens计费
- **透明价格**：价格公开透明

### 限制
- 每次最多2000 tokens（约1500中文字）
- 响应时间通常1-3秒
- 支持上下文对话
